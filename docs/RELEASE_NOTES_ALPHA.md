A mining adventure in your terminal. Explore three seeded floors of a castle hidden beneath a forest, dig through rock, collect crystals, and find the portals below.

- Play offline with automatic saves and a 512-action expedition limit.
- Switch between colored glyphs and half-block sprites. Fog stays enabled; there is no camera shake.
- Drive the same game through a plain-text headless interface with your own external agent.
- Choose Linux x86-64, Windows x86-64, macOS Apple silicon, or macOS Intel. Each ZIP includes installation instructions and license notices; matching SHA-256 files identify the archives.

**Alpha has no token payouts and requires no wallet or proof tool.** The planned $DCG token launch and future gameplay rewards are separate milestones.

Use a full-color UTF-8 terminal at least 90 columns by 30 rows. Extract the ZIP, open a terminal in its folder, and run `diggerchain` (`diggerchain.exe` on Windows). On Linux/macOS, run `chmod +x diggerchain` first if needed. Q saves and exits; `--new` starts another expedition. See the bundled `INSTALL.md` for controls, saves, and agent commands.

Native compilation and packaging do not replace platform runtime acceptance. The maintainer has deferred additional runtime tests. Windows/macOS binaries are unsigned. Unlimited descent, combat, and additional biomes are not part of this alpha.
