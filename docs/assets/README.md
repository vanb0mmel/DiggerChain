# Repository images

`castle-banner.webp` is a format-optimized copy of the original campaign painting in `tools/promo/media/castle.png`. Its exact built-in generation prompt is retained in the source PNG metadata and the adjacent WebP sidecar. No external reference painting is distributed.

`gameplay.webp` is a frame at 12 seconds of the landscape film composed with fframes. The terminal window is actual captured DiggerChain output; the surrounding art and title are campaign composition. It is production media, not a new gameplay test or a fabricated game screen.

The campaign artwork was generated with the built-in image-generation tool; exact prompts are preserved rather than inferred from the rendered image.
